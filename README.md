A three-page personal homepage that introduces my background, software projects,
technical skills, and public contact information.

## Project Objective

The objective is to give classmates, instructors, recruiters, and collaborators a clear
overview of who I am and what I have worked on. The site also demonstrates semantic
HTML5, responsive CSS, and an original JavaScript skill filter written with ES6 modules.

## Technologies Used

- HTML5
- CSS3 with Grid and Flexbox
- Vanilla JavaScript with ES6 modules
- Node.js and npm for development checks
- Class ESLint configuration
- Prettier

The project does not use a backend, jQuery, Bootstrap, or a component framework.

## How to Install and Use

1. Clone or download this repository.
2. Run `npm install` to install development tools.
3. Start a local static server in the project directory.
4. Open `index.html` through the local server.

The site is static and has no build step. Run the project checks with:

```sh
npm run lint
npm run format:check
```

## Pages

- `index.html` - Personal introduction and selected projects
- `skills.html` - Résumé-based skills with a JavaScript category filter
- `contact.html` - AI-assisted contact page

## JavaScript Feature

The Skills page lets visitors filter skill cards by category. The feature uses original
vanilla JavaScript and local HTML data; it does not use an external library or API.
